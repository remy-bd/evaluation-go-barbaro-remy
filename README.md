# evaluation-go-barbaro-remy

Nom : Barbaro--Debray
Prénom : Rémy

Exercice 1 :
Le programme qui simule un distributeur de boissons, on dois séléctionner une
boisson puis insérer de la monnaie pour payer. Si on n'insère pas suffisement
de monnaie le programme nous dit "monnaie insuffisante" et si on insère suffisement
de monnaie le programme nous rend la monnaie si nécessaire.

Exercice 2 :
Le programme simule un gestionnaire de note, on dois rentrer le nombre de note que
l'on souhaite entrer dans le gestionnaire de note. Pus on rentre toutes les notes
et le programme nous renvoi la moyenne des notes, la note la plus haute et la
note la plus basse. De plus, si la moyenne des notes est supérieur a 10, le
programme renvoi "Vous êtes admis !", sinon il renvoi "Non admis...".
